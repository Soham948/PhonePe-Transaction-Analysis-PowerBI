# PhonePe Transaction Analysis Dashboard | Power BI

## Overview
This project presents a Power BI dashboard report for analyzing PhonePe transaction activity across multiple service categories. The report focuses on transaction amounts, payment status, failed-payment reasons, monthly trends, loan services, money transfers, and recharge services.

The dashboard covers the date range **January 1, 2024 – December 30, 2024**, as displayed in the report.

## Project Objectives
- Analyze transaction amounts and transaction volumes.
- Compare successful and failed payments.
- Identify common reasons for failed transactions.
- Explore monthly transaction and amount trends.
- Review service categories such as Insurance, Loans, Money Transfer, and Recharge & Bills.
- Examine loan types, transfer types, and recharge categories shown in the report.

## Tools Used
- **Power BI Desktop** — dashboard design and data visualization
- **PDF** — exported report for viewing and sharing

> Note: This repository currently documents the exported PDF report. The source `.pbix` file and underlying dataset are not included unless added separately.

## Dashboard Pages
The report contains five pages with different analytical views:

1. **Service and Transaction Overview** — transaction amounts by service, monthly amount trends, payment totals, and failed-payment reasons.
2. **Payment Status and Premium Trends** — payment status breakdown, transaction totals, failed-payment reasons, and monthly premium trends.
3. **Loan Analysis** — loan amounts by loan type, monthly loan amount trends, transaction counts, and user counts.
4. **Money Transfer Analysis** — transfer types, transaction amounts by month, user counts, and payment status.
5. **Recharge Analysis** — recharge categories, monthly transaction amounts, transaction counts, and payment status.

## Highlights from the Report
- The report displays a total amount of approximately **512.92M** on one dashboard page.
- One page shows **300K total transactions**, while other pages present their own transaction counts and service-specific measures.
- The report compares successful and failed payments and visualizes several failure reasons, including wrong PIN, server error, insufficient amount, and bank denial.
- Monthly charts show how amounts, premiums, and loan amounts vary across the year.
- Service-level views include Insurance, Loan, Money Transfer, and Recharge & Bills.

**Important:** These figures are transcribed from the dashboard export and may represent different measures, filters, or pages. They should not be combined into a single calculation without checking the underlying Power BI model and filters.

## Key Business Questions
- Which services contribute the most transaction value?
- How do transaction amounts change month by month?
- What are the most frequently displayed reasons for payment failure?
- How do successful and failed payments compare?
- Which loan and transfer categories are represented in the report?
- What patterns appear across recharge services?
